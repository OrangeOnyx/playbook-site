Contents

Plain-markdown canonical files; friendly titles inside the documents. Every canonical page carries owner, review date, and version.

After Starter, "See it working this week"

  1. Workflow brief (workflows/<name>.brief.md), one page, with baseline metrics and the critical incident.
  2. “How I operate” one-pager (USER.md), quote-backed, with the unflattering finding.
  3. Workflow context brief (CONTEXT.md), NEVER DO block on top.
  4. One workflow procedure (procedures/<name>.md), five acceptance checks.
  5. Operator brief, lite (operators/<name>.md), manual cadence, no tool permissions, run log started.
  6. Evidence Log (LOG.md), at least one real run recorded.

After Frontier Operator, "Automation and portability" (adds)

  1. Automation decision map(s) (automations/<name>.md), including documented “stay assisted” decisions.
  2. Agent registry (section of AGENTS.md), one line per live operator or automation.
  3. Operating review & recovery plan, full (REVIEW.md + RECOVERY.md), 30/90/180/365 calendar, handoff rehearsed, portability run executed or gap explicit.
  4. Executive status report (STATUS.md), one page for the payer: installed, passed, baseline vs. current, next 90 days.
  5. Graduation set (print), bound canonical pages, completion map with test evidence and dates, before/after baseline comparison.

Every artifact on this list ends with its implementation intention, written with the participant and rehearsed once. Any document that has served no decision or output in the last 30 days is a candidate for archive, not maintenance, a standing item on the operating review agenda.
